# Machine Test for Automation Testing Internship

## **Project Title: Automation Testing of Calley Team Account full Setup**

### **Objective:**

The objective of this machine test is to assess the candidate's ability to automate essential functionalities of a web-based user management system using Selenium and TestNG in Java. The candidate is required to create automation scripts for user registration and Calley Team account setup, which includes login, agent creation, and list distribution through CSV upload.

### **Instructions:**

1. **Create a Maven Project** using any IDE (Eclipse, IntelliJ, etc.)
2. Use **Java** as the programming language.
3. Use **Selenium WebDriver** for browser automation.
4. Use **TestNG** as the testing framework.
5. Implement **Page Object Model (POM)** for better code structure.
6. Use a **data-driven approach** to handle inputs for tests.

### **Test Scenarios:**

**1. User Registration**

**Objective:** Automate the registration process for a new user.

- Navigate to the registration page.
- Enter required details (e.g., Name, Email, Phone, Password, etc.).
- Submit the form.
- Validate if the user is registered successfully.
- Select the Plan as Calley Teams.

**2. User Login**

**Objective:** Automate the login functionality.

- Navigate to the login page.
- Enter valid credentials.
- Verify successful login.

**3. Add Agents**

**Objective:** Automate the process of adding agents.

- Navigate to the agent page.
- Enter agent details.
- Submit the form.
- Validate if the agent is added successfully.

**4. Upload CSV of List**

**Objective:** Automate the CSV upload functionality.

- Navigate to Call List > Power Import.
- Enter List Name, select agents and upload the .csv file.
- Map the fields and Click on Import.
